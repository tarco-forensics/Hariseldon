Kelly Kriteri Açıklaması

Kelly kriteri, bankroll'un yüzde kaçının bahse konulması gerektiğini beklenen değer üzerinden optimal biçimde hesaplar.

# Kelly Kriteri f = (b * p - q) / b # b = net odds (odds - 1) # p = model kazanma olasılığı # q = 1 - p (kaybetme olasılığı) # Fraksiyonel Kelly (güvenli versiyon) stake = (f / 4) * bankroll # 1/4 Kelly

Bookmaker Türü: Sharp vs Soft Karşılaştırması
✓ Sharp Bookmaker'lar (Önerilen)
  • • Pinnacle: Düşük marj (~1.5%), kazananlara limit uygulamaz
  • • Betfair Exchange: Komisyon bazlı, sharp para kabul eder
  • • Asian Handicap: Derin likidite, düşük marj
  • • Kapanış çizgisini referans alır, piyasayı bilgilendirir
✗ Soft Bookmaker'lar (Dikkat)
  • • Bet365, W.Hill: Yüksek marj (~7%), kazananları hızlı kısıtlar
  • • Sharp parayı "zararlı" olarak kategorize eder
  • • Ortalama kısıtlama: ilk kazanmalardan itibaren haftalarca
  • • KYC gecikmesiyle çekim sürecini uzatabilirler
